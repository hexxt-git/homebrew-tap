# homebrew-tap

Homebrew formulae for [hexxt-git](https://github.com/hexxt-git) tools.

## Install

```console
brew install hexxt-git/tap/umm
```

Or tap first, then install:

```console
brew tap hexxt-git/tap
brew install umm
```

## Formulae

- **[umm](Formula/umm.rb)** — a faster way to ask; direct, structured answers in
  your terminal. Source: [hexxt-git/umm](https://github.com/hexxt-git/umm).
